# Esquemas de Base de Datos — Salud Vital

Módulo del proyecto **Salud Vital** orientado a la definición y organización de estructuras de datos utilizadas por el sistema.

## Objetivo

Centralizar modelos y componentes relacionados con la capa de datos del proyecto, facilitando una arquitectura modular y mantenible.

## Tecnologías

- Java
- Maven
- SQL / persistencia de datos

## Estructura

- `src/`: código fuente del módulo.
- `pom.xml`: configuración y dependencias de Maven.
- `target/`: archivos generados durante la compilación. Esta carpeta no debería conservarse en versiones futuras del repositorio y se recomienda excluirla mediante `.gitignore`.

## Relación con Salud Vital

Este repositorio forma parte de una solución dividida en varios módulos. Otros repositorios del perfil contienen la interfaz, API, persistencia, aplicación móvil y sistema principal.

## Estado

Proyecto académico utilizado para practicar separación de responsabilidades y arquitectura por módulos.
